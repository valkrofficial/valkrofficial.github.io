VALKR GUIDE

Log working sets you can compare later.

A workout log is useful when it describes what you actually did. This guide walks through set logging in VALKR and explains how to distinguish targets, completed performance and later corrections.

1. Check the exercise before the first set

Open the planned session and check the exercise name, order and target in its overview. Then start the workout screen. The selected exercise is the basis for later comparisons. A similarly named machine exercise is not automatically the same movement as a barbell exercise.

VALKR displays previous performance and set targets when matching logs exist. A target is not a completed set. When you have no personal history, do not invent a previous load just to make the overview look complete.

2. Distinguish warm-up sets from working sets

The workout screen supports separate warm-up blocks. Check which section you are recording. Do not record a preparatory set as a hard working set just to increase the completed-set count. This guide concerns documentation; your warm-up depends on your training plan and situation.

3. Record actual load and repetitions

Example: the target is three sets of eight repetitions. With the same load, you actually complete 8, 8 and 6. Save those three results separately. Recording three sets of eight would claim performance you did not achieve and distort later progression guidance. These numbers are a logging example, not a personal training prescription.

For a weighted exercise, load and repetitions belong to each individual set. Use a consistent load convention for the same exercise. If the equipment or movement changes, do not copy the old number without checking. For holds, record the intended time unit rather than repetitions.

4. Correct an inaccurate entry

You can correct a previous set in the workout screen. After an accidental entry, review the affected set and adjust its actual values. Do not create another set to record the same effort correctly: your history would then contain two efforts instead of one.

Reloading the workout screen is not a reason to enter completed sets again. The app saves the running workout state. First inspect existing entries and the displayed section. Actual continuation on Android also requires device validation.

5. Review history after the session

Compare the same exercise under similar conditions: load, repetitions and actually logged sets. More repetitions with the same load differ from fewer repetitions with a heavier load. One personal best does not explain every training change.

Rule-based set guidance and “Why this target?” help explain the next target. Estimated one-rep max remains a calculated value. Accurate history improves the basis of these displays; it does not replace technique assessment or an individual training decision.
